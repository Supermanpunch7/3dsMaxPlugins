# 3dsMaxPlugins

Custom C++ plugins for Autodesk 3ds Max.

## Plugins Included

- **ChamferPro**: Advanced Chamfer plugin implementation for 3ds Max.
- **OpenSubdivPro**: High-performance subdivision surface plugin for 3ds Max using OpenSubdiv SDK.

## Requirements

- Autodesk 3ds Max 2027 SDK (or compatible version)
- Visual Studio 2022 (MSVC C++ Toolset)
